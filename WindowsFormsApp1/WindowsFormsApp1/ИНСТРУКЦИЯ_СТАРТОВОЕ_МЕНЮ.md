# Инструкция: Создание отдельной сцены для стартового меню с черным фоном

## Цель
Создать отдельную сцену `StartupMenu.unity`, которая будет содержать ТОЛЬКО черный фон и меню выбора, без каких-либо других объектов (деревьев, окружения и т.д.).

---

## Шаг 1: Создание новой сцены

1. **В Unity Editor:**
   - Откройте меню `File → New Scene`
   - Выберите `Basic (Built-in)` или `Empty Scene`
   - Сохраните сцену как `StartupMenu.unity` в папке `Assets/Scenes/`

2. **Проверьте путь:**
   ```
   Assets/Scenes/StartupMenu.unity
   ```

---

## Шаг 2: Настройка камеры для черного фона

1. **Найдите или создайте Main Camera:**
   - Если камеры нет: `GameObject → Camera`
   - Если камера есть: выберите её в Hierarchy

2. **Настройте камеру:**
   - **Position:** `(0, 1.6, 0)` или `(0, 0, 0)`
   - **Rotation:** `(0, 0, 0)`
   - **Clear Flags:** `Solid Color` (важно!)
   - **Background:** `Black` (RGB: 0, 0, 0)
   - **Tag:** `MainCamera`

3. **Удалите все лишние компоненты:**
   - Убедитесь, что на камере нет компонентов, которые могут показывать что-то (например, Post Processing)

---

## Шаг 3: Настройка Render Settings

1. **Откройте Render Settings:**
   - `Edit → Project Settings → Graphics` (или через `Window → Rendering → Lighting Settings`)

2. **Настройте для черного фона:**
   - **Fog:** Отключите (`Fog` = `false`)
   - **Ambient Light:** Установите `Black` (RGB: 0, 0, 0)
   - **Skybox Material:** Удалите или установите `None`

---

## Шаг 4: Очистка сцены от лишних объектов

1. **Проверьте Hierarchy:**
   - Должны быть ТОЛЬКО:
     - `Main Camera`
     - `Directional Light` (можно оставить, но лучше удалить или отключить)
     - `EventSystem` (будет создан автоматически при создании меню)

2. **Удалите все лишнее:**
   - Удалите `Directional Light` (или отключите его: `GameObject → Set Active` = `false`)
   - Удалите все объекты, связанные с окружением (деревья, платформы и т.д.)
   - Удалите все объекты, связанные с модулями (Exposure, EMDR, Safe Place и т.д.)

3. **Проверьте, что в сцене НЕТ:**
   - ❌ Объектов с названиями: "Forest", "Sea", "Mountain"
   - ❌ Объектов с названиями: "Exposure", "EMDR", "SafePlace"
   - ❌ Любых 3D моделей или объектов окружения
   - ❌ Планов (Plane), кубов (Cube), сфер (Sphere) и т.д.

---

## Шаг 5: Добавление AutoSetup скрипта

1. **Создайте пустой GameObject:**
   - `GameObject → Create Empty`
   - Назовите его `AutoSetup`

2. **Добавьте компонент VRPTSD_AutoSetup:**
   - Выберите `AutoSetup` в Hierarchy
   - В Inspector нажмите `Add Component`
   - Найдите и добавьте `VRPTSD_AutoSetup`

3. **Проверьте настройки:**
   - Компонент должен быть включен (`Enabled` = `true`)

---

## Шаг 6: Настройка Build Settings

1. **Откройте Build Settings:**
   - `File → Build Settings`

2. **Добавьте сцену StartupMenu:**
   - Нажмите `Add Open Scenes` (если сцена открыта)
   - ИЛИ перетащите `StartupMenu.unity` из Project в список сцен

3. **Установите StartupMenu как первую сцену:**
   - Перетащите `StartupMenu.unity` в самый верх списка (индекс 0)
   - Это сделает её сценой, которая загружается при запуске игры

4. **Проверьте порядок сцен:**
   ```
   [0] StartupMenu.unity
   [1] SampleScene.unity (или другая стартовая сцена)
   [2] World_Forest.unity
   [3] World_Sea.unity
   ```

---

## Шаг 7: Настройка WorldSceneController

1. **Откройте скрипт `WorldSceneController.cs`:**
   ```
   Assets/Scripts/WorldSceneController.cs
   ```

2. **Проверьте поле `startupSceneName`:**
   - Должно быть: `public string startupSceneName = "StartupMenu";`
   - Это нужно для возврата в меню из других сцен

3. **Сохраните изменения**

---

## Шаг 8: Проверка результата

1. **Запустите игру:**
   - Нажмите `Play` в Unity Editor

2. **Проверьте:**
   - ✅ Экран полностью черный
   - ✅ Видно только меню с кнопками
   - ✅ Нет деревьев, фона или других объектов
   - ✅ Нет тумана или других эффектов
   - ✅ Меню работает (кнопки кликабельны)

---

## Шаг 9: Дополнительная настройка (опционально)

### Если всё равно видны объекты:

1. **Проверьте VRPTSD_AutoSetup.cs:**
   - Убедитесь, что все объекты окружения создаются с `SetActive(false)`
   - Убедитесь, что вызывается `HideAll()` для всех контроллеров

2. **Проверьте StartupMenuController.cs:**
   - Убедитесь, что `PreviewSelectedWorld()` закомментирован или не вызывается
   - Убедитесь, что вызывается `environmentController.HideAll()`

3. **Проверьте камеру:**
   - Убедитесь, что `Clear Flags` = `Solid Color`
   - Убедитесь, что `Background` = `Black`

---

## Итоговая структура сцены StartupMenu:

```
StartupMenu (Scene)
├── Main Camera
│   ├── Clear Flags: Solid Color
│   ├── Background: Black
│   └── Tag: MainCamera
├── AutoSetup (GameObject)
│   └── VRPTSD_AutoSetup (Component)
└── EventSystem (создается автоматически)
```

**В сцене НЕ ДОЛЖНО БЫТЬ:**
- Directional Light (или отключен)
- Любых 3D объектов
- Любых объектов окружения
- Любых модулей (Exposure, EMDR и т.д.)

---

## Быстрая проверка:

1. Откройте сцену `StartupMenu.unity`
2. В Hierarchy должно быть максимум 2-3 объекта
3. Запустите игру
4. Экран должен быть полностью черным с меню

---

## Решение проблем:

### Проблема: Видны объекты в фоне
**Решение:**
- Проверьте `Clear Flags` камеры = `Solid Color`
- Проверьте `Background` камеры = `Black`
- Отключите `Fog` в Render Settings
- Удалите все объекты из Hierarchy, кроме Camera и AutoSetup

### Проблема: Меню не появляется
**Решение:**
- Проверьте, что `VRPTSD_AutoSetup` компонент включен
- Проверьте консоль Unity на ошибки
- Убедитесь, что `StartupMenuController` создается правильно

### Проблема: Сцена не загружается при запуске
**Решение:**
- Проверьте Build Settings
- Убедитесь, что `StartupMenu.unity` добавлена и стоит первой (индекс 0)
- Сохраните сцену перед добавлением в Build Settings

---

Готово! Теперь у вас есть отдельная сцена для стартового меню с полностью черным фоном.
